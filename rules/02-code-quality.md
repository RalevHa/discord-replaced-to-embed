# 02 · Code Quality

- Write readable, maintainable code.
- Split code into functions/classes by responsibility (Single Responsibility).
- Avoid duplicate code (DRY).
- Use meaningful function and variable names.
- Remove dead code; do not leave commented-out code lying around.
- Follow SOLID and KISS; keep functions small and modules independent.
- Add comments only when they explain *why*, matching the surrounding density.
