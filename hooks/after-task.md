# AfterTask checklist

- [ ] Run the real test/lint command; if none, verify manually and state how.
- [ ] Report results faithfully — if it failed or a step was skipped, say so.
- [ ] Hand the diff to `tester` (and `security-engineer` if auth/data was touched).
- [ ] Capture new how-tos/gotchas as a `skills/` file — **merge into an existing one, don't duplicate**.
- [ ] Save user/project-level facts (not derivable from code) to Memory.
- [ ] Update only the affected docs (README / API / Database / Architecture / Changelog / Migration / Config).
- [ ] Produce the closing summary: work done, real test results, knowledge/docs updated, architectural impact, next step.
