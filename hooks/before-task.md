# BeforeTask checklist

- [ ] Read `project_rules.md` and the relevant `rules/`.
- [ ] Read only the `skills/` and `agents/` related to this task.
- [ ] Detect the real stack and confirm which test/lint command applies.
- [ ] Review recalled Memory — confirm it still matches the real code.
- [ ] Search for an existing implementation to reuse before planning new code.
- [ ] Know the contracts/conventions you must preserve and which files you will touch.
- [ ] Pick the right agent for the work.
